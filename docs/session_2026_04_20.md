# Session: April 20, 2026

## Fixes Delivered

### 1. Kessler Saturation Mixing Ratio (CPU + GPU)
Replaced hardcoded `qvsat = 0.001` with proper thermodynamic computation using the Buck equation. At 300K/100kPa, the real qvsat is ~0.023 -- the old value was 14x too low, causing rain evaporation to be drastically under-predicted.

- CPU: `thermodynamics::saturation_mixing_ratio_water(T, p)` and `_ice(T, p)`
- GPU: Inline GLSL implementation in `kessler_pointwise.comp`
- Added pressure field through the full GPU dispatch chain (7 input buffers, 13 SSBOs)
- Updated all tests to use physically correct saturation values

### 2. Equation-of-State Density Closure
The dynamics computes buoyancy as `-g(rho - rho0)/rho`, but rho was never updated when theta changed. A warm bubble perturbation of +2K had zero dynamical effect.

- Added `thermodynamics::density_from_eos(p, theta)` computing `rho = p / (R_d * T)`
- Applied at initialization after the bubble modifies theta
- Applied at the end of each dynamics step after all physics modify theta
- Result: warm bubble now produces correct buoyancy-driven convection

### 3. Saturation Adjustment for Kessler and Milbrandt
Kessler and Milbrandt had no saturation adjustment -- vapor never condensed to cloud water. With qc=0 and qr=0 initially, all microphysics processes produced zero tendencies.

- Added saturation adjustment before warm-rain physics in both schemes
- All 4 microphysics schemes now produce differentiated storm evolution
- Lin produces noticeably different dynamics (weaker downdraft by ~21%)

### 4. Rayleigh Damping Sponge Layer
Convection reflected off the rigid domain top, creating an amplifying feedback loop.

- Added `apply_rayleigh_damping()` in `src/core/infra/rayleigh_damping.cpp`
- Sine-squared damping profile: alpha(z) = alpha_max * sin^2(...) in top 30% of domain
- Relaxes u, v, w, theta, rho, p toward environmental base state
- Wired into `step_dynamics_new()` after EOS update, before BCs

## Remaining Work

### Dynamics Stability (next priority)
The simulation produces 5+ minutes of physical convection before blowing up. Root causes:
- **Weak environmental stratification**: theta only increases 13K over 16km (should be ~70K). The atmosphere has excessive CAPE with no tropopause "lid."
- **Bottom boundary reflection**: strong downdrafts reflect off the rigid ground boundary. A bottom sponge or open BC would help.
- **Collocated grid**: all variables at cell centers allows 2-delta-x computational modes. The standard fix is an Arakawa C-grid (staggered), but that's a major refactor. 4th-order hyperdiffusion is the practical alternative.

### Physics Coupling Verification
- Radiation, BL, and turbulence tendencies are being computed and applied but produce effects below the diagnostic threshold at 300s on a 2km grid. Longer stable runs (enabled by stability fixes) will show their contributions accumulate.
- The physics coupling chain is complete: theta -> EOS -> rho -> buoyancy -> w.
